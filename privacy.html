Privacy Policy

Family Finance Monitor · Last updated: October 2, 2026

Family Finance Monitor is a private application used by a single owner for their own personal and business finances. It is not offered to, and has no accounts for, anyone else.

What it accesses

With the owner's explicit authorization through Intuit's OAuth sign-in, the application reads accounting data from the owner's own QuickBooks Online companies: account names and balances, and transactions (date, amount, payee, category, memo). It uses read-only requests only and never creates, changes or deletes anything in QuickBooks.

Where the data is stored

All data is stored only on the owner's own computer, in a local database. Intuit access and refresh tokens are encrypted at rest, and the encryption key is held in the computer's secure keychain. The application's dashboard is reachable only on the owner's private network.

Sharing and use

The data is not sold, shared with or disclosed to any third party, and is not used for advertising or profiling. It is used solely so the owner can review their own finances.

Retention and deletion

Data is kept for as long as the owner uses the application. The owner can disconnect the application at any time from QuickBooks (Apps → My Apps) and can delete all stored data by deleting the local database.

Security

Access to the dashboard requires a password. Credentials issued by Intuit are stored locally and never committed to source control.

Changes and contact

If this policy changes, the date above will be updated. Questions can be raised through this site's GitHub repository.
